# Влияние приложения для медитации на время засыпания

Итоговый проект курса «Аналитик данных» по теме «Постановка и проверка гипотез».

## Цель

Проверить, сокращает ли использование мобильного приложения с вечерними медитациями время засыпания у участников исследования.

## Данные

Парные наблюдения по 50 добровольцам (после очистки — 44):
- `participant_id` — идентификатор участника;
- `age` — возраст;
- `before_min` — среднее время засыпания за неделю до использования приложения;
- `after_min` — среднее время засыпания за неделю после 4 недель использования.

Данные генерируются ячейкой внутри ноутбука (фиксированный `seed`), отдельный файл с данными не нужен.

## Что сделано

1. **Очистка данных** — обработка пропусков, дубликатов, нереалистичных значений, приведение типов, формирование возрастных групп.
2. **Разведочный анализ** — гистограмма и boxplot разностей, подсчёт улучшивших/ухудшивших.
3. **Проверка нормальности** — критерий Шапиро-Уилка, Q-Q график.
4. **Проверка гипотезы** — парный t-критерий (левосторонний) + 95% доверительный интервал.
5. **Непараметрическая проверка** — критерий знаковых рангов Уилкоксона.
6. **Сравнение с ошибочным непарным тестом** — демонстрация потери мощности.
7. **Размер эффекта** — Cohen's d для парных данных.
8. **Гипотеза о доле улучшивших** — биномиальный тест + ДИ доли.
9. **Итоговые выводы** — заключение для бизнеса с ограничениями.
10. **Бонус** — сравнение эффекта между возрастными группами «до 35» и «35 и старше».

## Главный вывод

Приложение статистически значимо сокращает время засыпания: в среднем на **3.11 минуты** (95% ДИ: от 1.84 до 4.39 мин, или ~9.4% от исходного уровня), эффект среднего размера по шкале Коэна ($|d_z| = 0.744$) и подтверждён несколькими независимыми методами. Без контрольной группы нельзя исключить эффект плацебо и сезонность — рекомендуется провести A/B-тест с группой сравнения.

## Как запустить

1. Создайте и активируйте виртуальное окружение (опционально):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/macOS
   .venv\Scripts\activate     # для Windows
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Откройте Jupyter Notebook и запустите все ячейки (**Kernel → Restart & Run All**):
   ```bash
   jupyter notebook
   ```
